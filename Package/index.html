01 / ORIGINAL

"HeLLo WorLD"

lamaGkh

GENRE : "HeLLo WorLD"

JACKET : Frill-buriburi-obake
COMMENT

lamaGkh 24平均律を用いた微分音の使用、今まで作ったことのないテイストの楽曲に挑戦しました。 地球外生命体のデータが地球人の手にわたり、恐る恐る開いたところ流れてきた音楽というテーマです。 今の人類にとって未知のモノ、異物であるという印象を植え付ける曲に仕上げたつもりです。 Frill-buriburi-obake 初めてメカキャラクターデザインをしました。少し悩みましたが、なんだかんだ形になってうれしく思っています。 楽曲の不穏さ、不気味さを表現するために、顔の中心パーツをむき出しにしてみたりして、なんだか話が簡単に通じなさそうな形に仕上がったかな、と思います。 お気に入りポイントは、髪の毛に見立てた切れたコードです。 実はこの絵の中に作曲者と私がいます。すぐに見つけられると思いますが探してみてください。一気にこのイラストの印象が変わります。

04 / ORIGINAL

Filia -無色透明-

RyuL

GENRE : DISTANT MEMORY

JACKET : UMR
COMMENT

RyuL 今回は龍と子供の、出会いと別れ、そして再会の曲となっています。 長い年月が過ぎ、数多の世界を超えても、お互いを忘れず、最後には感動の再開を果たす、そんなストーリーから曲を作りました。 いつも曲を作るときはストーリーがあるのですが、同じ世界線で考え始めてから7年経ってるので、どんどん複雑になってきてます… ちなみに、とんえぼパッケージで龍の曲を合計3曲出しているのですが、頭文字がA～Gまで揃うように作ってました。 (欠けている曲は機会があれば…) UMR この楽曲を聴いて自分がまず最初に想起したのは、離れ離れになった龍と少年の、運命の再会のシーンです。 楽曲イントロのハミングっぽいメロディを「少年の歌」になぞらえ、ひとり龍を想い歌い続ける少年の姿をイメージしました。 そしてラスサビ開始と同時に唸る笛のような音が「龍の咆哮」に聴こえたので、これに気付いた少年が振り返る、その視線の先には…という瞬間を描いたジャケットになります。 楽曲が速いので疾走感も意識しつつ、ケルトな雰囲気も出したいから恰好は冒険者かな…など、諸々ごった煮になってしまった気もしますが、無事（？）完成してくれてよかったです。 この度はお声かけいただきありがとうございました！

sendaijiro 00(~10)年代を振り返りながら書いた曲です。 編曲部分は今できる全てをつぎ込みました。 郷愁やなつかしさを覚える人がいたら嬉しいです。 Leruna 何か新しいことをしなくてはということで、普段使っているカラーパレットを封印しました。 趣味で撮り貯めている夕暮れ空の写真を1枚選んでそこからスポイトで吸った色だけで描いています。写真内に白と黒と肌塗るのに使えそうな色があって良かった～！ カラーパレットとして使った写真は背景にもしています。よく見えるように思い切って差分1枚はほぼ背景だけにしました。よ～く見ると下の方に木の頭が見えるかも。 差分は「薄れゆく」イメージで作ってます。「逆じゃない？」って思います？でもどうせみなさん一番上の難易度やってから順番に下げていく形で下埋めてるんでしょ？逆じゃないんですねえ。

12 / ORIGINAL

Fierté et croyance

Asymmetry Surge

GENRE : EMO Trance

JACKET : UMR
COMMENT

Asymmetry Surge 本楽曲は2人での合作となっています。 トランスと一口に言っても様々なジャンルがあり、また方向性も多岐にわたります。 今回は2人の好きな"エモ"に舵を切ることにしました。 トランスは歴史が長いクラブミュージックで、今もなお多彩な形で生まれ続けています。 この曲をきっかけに、少しでもトランスに触れてくださる方がいましたら幸いです。 UMR この楽曲はジャケットのイメージがなかなか出てこなくて難産でした… トランスは好きでよく聴きますし、美しさと少しの黒さ、儚さを孕んだ激良曲なのですが、これを表現する方法が分からなくて。 個人的には無機物的な表現がしたいと思ったのですが、それをお絵かきソフトで描く技量が無く、どうしたものかと色々悩みました。 女の子しか描けない自分なのでそこは中心に据えつつ、kawaii系よりも美しい系だろうということで、欲しかった無機物要素の中に天使を座らせる構図に落ち着きました。 自分が昔から大好きな楽曲を参考にしたりと模索したのですが、なんだか色々と違いますね笑 でも最終的には、描きたかった情景ぽくなったかな、と思います！ この度はお声かけいただきありがとうございました！
